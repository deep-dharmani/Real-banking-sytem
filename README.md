🏦 Python Banking System

A Python-based Banking System that simulates basic banking operations such as account creation, authentication, deposits, withdrawals, and balance management.

This project started as a simple Python application using Object-Oriented Programming (OOP) and JSON file handling. Later, I extended it using **FastAPI** to implement banking operations through REST API endpoints.

🚀 Features

1. Simple Python Version
- Account authentication using account number and password
- Deposit money
- Withdraw money
- Check account balance
- Object-Oriented Programming (OOP)
- Encapsulated account balance
- JSON-based data persistence

2. FastAPI Version
- Create new bank accounts
- CNIC format validation
- Automatically generated account numbers
- Deposit money through API endpoints
- Withdraw money through API endpoints
- Account number and password verification
- JSON-based account storage
- REST API development using FastAPI

🛠️ Technologies Used
- Python
- FastAPI
- Pydantic
- Uvicorn
- JSON
- Regular Expressions (Regex)
- Object-Oriented Programming (OOP)

⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/deep-dharmani/Real-banking-sytem.git
```

Navigate to the project directory:

```bash
cd Real-banking-sytem
```

Install the required dependencies for the FastAPI version:

```bash
pip install fastapi uvicorn pydantic
```

▶️ Running the Project

Simple Python Version

```bash
python Simple_python_programme.py
```

FastAPI Version

```bash
python fast_api_based.py
```

After starting the FastAPI application, open:

```text
http://127.0.0.1:8000/docs
```

You can explore and test the available API endpoints through Swagger UI.
